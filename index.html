EXERCISE 9 · DATABASE MANAGEMENT

MongoDB Shell Interactive Commands

Complete record commands for Electronics E-MART database using mongosh. Create collections, insert electronics items, perform CRUD operations, and run sorting queries.

🍃 MongoDB 6.0+ 💻 Database: ElectronicsEMartDB 📦 Collection: products
1. Database & Collection Setup 
// 1. Switch to E-Mart Database
use ElectronicsEMartDB

// 2. Create products collection
db.createCollection("products")
2. Inserting Electronic Products (insertOne & insertMany) 
// Insert single product
db.products.insertOne({
  productId: 201,
  name: "Galaxy Ultra S26",
  category: "Smartphones",
  brand: "Samsung",
  price: 124999,
  stock: 25,
  rating: 4.8
})

// Insert multiple electronics items
db.products.insertMany([
  { productId: 202, name: "ZenBook Pro 14", category: "Laptops", brand: "Asus", price: 89990, stock: 12, rating: 4.7 },
  { productId: 203, name: "SoundMax ANC Pro", category: "Audio", brand: "Sony", price: 14499, stock: 40, rating: 4.6 },
  { productId: 204, name: "PulseFit Watch 3", category: "Wearables", brand: "Noise", price: 9999, stock: 3, rating: 4.2 },
  { productId: 205, name: "iPhone 17 Pro", category: "Smartphones", brand: "Apple", price: 134900, stock: 18, rating: 4.9 }
])
3. Querying & Filtering Electronics 
// Display all products in readable format
db.products.find().pretty()

// Find products with price greater than 50,000
db.products.find({ price: { $gt: 50000 } })

// Find products in range 10,000 to 1,00,000
db.products.find({ price: { $gte: 10000, $lte: 100000 } })

// Find products matching specific categories
db.products.find({ category: { $in: ["Laptops", "Audio"] } })
4. Updating & Deleting Records 
// Update price of Asus ZenBook
db.products.updateOne({ productId: 202 }, { $set: { price: 84990 } })

// Increase stock of all smartphones by 10
db.products.updateMany({ category: "Smartphones" }, { $inc: { stock: 10 } })

// Delete low stock products (< 5)
db.products.deleteMany({ stock: { $lt: 5 } })
5. Sorting, Limiting & Database Stats 
// Top two costliest electronics
db.products.find().sort({ price: -1 }).limit(2)

// Total count of products
db.products.countDocuments()

// Database statistics and collections
show collections
db.stats()
